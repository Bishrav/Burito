# Vision

Burito is a local-first personal assistant for conversation, personal knowledge,
research, coding, and owner-authorized computer operations. It should carry
verified context across sessions, ask when the intent is ambiguous, distinguish
facts from inferences, and report completion only with evidence.

The Linux desktop hosts inference, private memory and execution. The MacBook
and iPhone are planned companions. Conversation comes first, then attributable
memory, voluntary voice and screen input, paired devices and durable tasks.

Burito should communicate naturally while accurately describing its capabilities,
uncertainty and limits. It makes no claims of consciousness or fabricated
emotion. Personalization starts with approved memory and retrieval. Model
fine-tuning is a separate, evaluated experiment with approved data and rollback.
