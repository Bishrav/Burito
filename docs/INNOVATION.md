# Research and innovation backlog

Begin these experiments after the prerequisite phases in the roadmap pass.

| Capability | First testable outcome |
| --- | --- |
| Cognitive continuity | Restore the last verified project checkpoint after a restart or paired-device handoff. |
| Explainable memory | Explain a recalled fact with its source, timestamp, confidence, evidence and correction history. |
| Workspace model | Answer project and app-state questions from authorized metadata with measurable collection limits. |
| Predictive preparation | Generate a useful, opt-in preparation brief without taking consequential actions. |
| Task checkpoints | Recover a synthetic workflow from its last verified checkpoint and report rollback evidence. |
| Learning from demonstrations | Save a reviewed, versioned workflow and pass a safe replay before enabling it. |
| Counterfactual planning | Compare prerequisites, failure modes and reversibility for two candidate plans using measured outcomes. |
| Portability | Export, import and verify versioned approved records on a clean test profile. |
| Model routing | Benchmark reliability, cost, latency, context and privacy-aware routing on fixed tasks. |
| Improvement lab | Test a proposed prompt or code improvement in isolation and require review before activation. |
